# AOP:TC4 Compact

[English](README.md)

Я поддерживаю необязательную интеграцию **JEI / EMI** и подсказки **Jade / WTHIT** для **AOP: Thaumcraft 4**, Minecraft **1.21.1 / NeoForge**. Поддержка устройств Thaumic Tinkerer включается при наличии аддона.

## Установка

Нужны Java 21, NeoForge от 21.1.252 в пределах 21.1, AOP: Thaumcraft 4 1.0.0 и хотя бы один просмотрщик:

| Интеграция | Поддерживаемые версии |
| --- | --- |
| JEI | от 19.8.4.110 до 20, не включая 20 |
| EMI | от 1.1.13 до 1.2, не включая 1.2 |
| Jade | от 15.10 до 16, не включая 16 |
| WTHIT | от 12.5 до 13, не включая 13 |

Все моды должны быть для Minecraft 1.21.1 / NeoForge. Установите и их зависимости. При наличии обоих просмотрщиков рецептов используется EMI. Jade и WTHIT работают независимо.

Поместите `aoptc4-client-compact-0.8.0.jar` в `mods` клиента. Старый `thaumcraft-viewers` JAR замените: оба одновременно не устанавливаются. Mod ID остаётся `thaumcraft_viewers`, чтобы сохранить совместимость настроек.

Установка на сервер необязательна. Вместе с Jade или WTHIT она даёт достоверные серверные данные блока. Без неё подсказки используют уже синхронизированные данные клиента; несинхронизированный инвентарь может быть недоступен. JEI/EMI на выделенном сервере не нужны. Thaumic Tinkerer необязателен с обеих сторон.

Рецепты показывают требования исследований, аспекты и стоимость виса. Настройки находятся в `thaumcraft_viewers-client.toml`. Неизученные аспекты скрыты. Подсказки TC4 показывают эссенцию через публичные контракты контейнеров и труб; подсказки Tinkerer — инструмент планшета, цель трансвектора, ремонт и режим магнита.

## Сборка

Установите JDK 21 и укажите совместимые API Thaumcraft и игровой JAR Thaumic Tinkerer:

```powershell
./gradlew.ps1 build -PthaumcraftApiJar=/path/to/thaumcraft-api-1.0.0.jar -PtinkererJar=/path/to/ThaumicTinkerer.jar
```

Можно поместить их в `libs/` с именами из `build.gradle`. Для Linux/macOS используйте `sh ./gradlew`. Зависимости не включаются в результат. Tinkerer нужен для компиляции его адаптера, но не обязателен при запуске.

`build` выполняет проверки представления рецептов и изоляции JEI/EMI, а также компилирует нативные проверки подсказок. Профили просмотрщиков: `check -PviewerCompatibility=minimum`, `middle` или `latest`. Для GameTest нужны явно указанные игровые JAR и параметры соответствующих интеграций. Проверки не означают визуальную приёмку всех сочетаний клиента и сервера.

## Настройка CI

Переменные репозитория `THAUMCRAFT_REPOSITORY` и `THAUMCRAFT_REF` выбирают исходники ядра (по умолчанию `Salossov/aop-thaumcraft-4`, `main`). Используйте совместимые ревизии ядра и аддона. Для приватных зависимостей checkout требует токен с правом чтения.
В этом репозитории задайте `TINKERER_REPOSITORY` как опубликованный `owner/repository`; `TINKERER_REF` по умолчанию равен `main`.
